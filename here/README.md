# Here — تطبيق طلبات وعضويات كوفي Here

<p align="center"><img src="public/icons/icon-192.png" width="96" alt="Here"></p>

تطبيق للعملاء يعرض منتجات **Here Specialty Cafe** ويستقبل الطلبات، مع **شاشة للكوفي**
تصلها الطلبات لحظيًا ببيانات العميل والسيارة أو العنوان، ونظام **عضويات ونقاط**.

> نسخة تجريبية: المنتجات والصور والأسعار أُخذت من قوائم Here المنشورة على منصات التوصيل
> (Talabat وDrivu) لأن انستقرام لا يسمح بالسحب الآلي. عدّل أي شيء من `data/menu.json`.

---

## ماذا يحتوي؟

| الجزء | الرابط | الوظيفة |
|---|---|---|
| **تطبيق العملاء** (PWA) | `/` | القائمة بالصور، خيارات المشروب (حليب/سكر/ثلج/شوت)، السلة، الطلب، تتبّع الحالة، بطاقة العضوية + QR، سجل النقاط. عربي/إنجليزي. يُثبَّت على الهاتف كتطبيق. |
| **شاشة الكوفي** | `/admin/` | لوحة الطلبات الحية (جديد ← تحضير ← جاهز ← تسليم) مع صوت وإشعار، بيانات السيارة/العنوان مع رابط الخريطة، إدارة المنتجات (إيقاف/سعر)، الأعضاء وإضافة نقاط للشراء المباشر، إحصائيات اليوم. |
| **الخادم** | `server.js` | Node 22 بلا اعتماديات. يحسب الأسعار من جهته (لا يثق بالعميل)، يحفظ البيانات في `data/db.json`، ويبثّ التحديثات عبر SSE. |
| **غلاف أندرويد** | `mobile/` + `.github/workflows/build-here-android.yml` | يبني APK بالاسم والأيقونة يفتح خادمك. |

### طرق الاستلام
1. **استلام من الكوفي** — يصل العميل إشعار «جاهز» ويستلم من الكاونتر.
2. **من السيارة** — يُدخل نوع السيارة ولونها ورقم اللوحة، وتظهر للكوفي بشكل بارز.
3. **توصيل** — عنوان نصي + زر «تحديد موقعي» (GPS) يولّد رابط خرائط جوجل للكوفي. رسوم وحد أدنى وتوصيل مجاني فوق مبلغ، كلها قابلة للتعديل.

### نظام العضويات والنقاط (قابل للتعديل من `data/menu.json` ← `loyalty`)
- تسجيل بالهاتف والاسم فقط (بلا كلمة مرور) + **50 نقطة ترحيبية**.
- **نقطة لكل درهم** (بعد الخصم) تُضاف عند اكتمال الطلب.
- **كل 100 نقطة = 10 دراهم خصم** على أي طلب، بحد 50% من قيمة الطلب. الإلغاء يُرجع النقاط.
- مستويات بحسب مجموع النقاط مدى الحياة: **عضو** ×1 · **فضي** (500+) ×1.25 · **ذهبي** (1500+) ×1.5.
- **بطاقة عضوية برمز QR** (مثل `HERE-3F9A2C`) يمسحها الكاشير من شاشة الكوفي ليضيف نقاط الشراء المباشر.

لماذا هذا التصميم؟ النقاط تُكسب بالإنفاق لا بعدد الطلبات (يصعب التلاعب)، والاستبدال بخطوات ثابتة
يُبقي الخصم مفهومًا للعميل وبسيطًا للكاشير، والمستويات تكافئ الولاء بلا تعقيد.

## التشغيل محليًا (دقيقة واحدة)

```bash
cd here
node server.js            # يتطلب Node 22+
# افتح http://localhost:3000       ← تطبيق العملاء
# افتح http://localhost:3000/admin ← شاشة الكوفي، الرمز الافتراضي 1234
```

اختبار ذاتي شامل (تسجيل، طلبات بالأنماط الثلاثة، حالات، نقاط، استبدال، إلغاء):

```bash
npm test
```

## النشر (ليعمل على هواتف العملاء)

يحتاج الخادم إلى رابط **https** ثابت. أسهل الخيارات:

**Docker على أي خادم/سحابة** (Railway, Render, Fly.io, أو VPS):
```bash
docker build -t here .
docker run -d -p 3000:3000 -v here-data:/data \
  -e ADMIN_PIN=رمز_قوي \
  -e TELEGRAM_BOT_TOKEN=... -e TELEGRAM_CHAT_ID=... \
  here
```

| متغيّر | الوظيفة |
|---|---|
| `ADMIN_PIN` | رمز دخول شاشة الكوفي. **غيّره** عن 1234. |
| `DATA_DIR` | مجلد حفظ `db.json` (افتراضي `./data`). اجعله على قرص دائم. |
| `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` | اختياري: يصل كل طلب جديد كرسالة تيليجرام لجوال الكوفي (أنشئ بوت عبر @BotFather وأضفه لمجموعة). |
| `PORT` | المنفذ (افتراضي 3000). |

بعد النشر: افتح الرابط من هاتف ← «إضافة إلى الشاشة الرئيسية» فيصبح تطبيقًا بأيقونة Here.
وشاشة الكوفي تعمل على أي جهاز لوحي أو كمبيوتر في الكوفي (فعّل زر 🔔 لسماع الطلبات الجديدة).

## تطبيق أندرويد (APK)

1. ضع رابط خادمك في **Settings → Secrets and variables → Actions → Variables** باسم `HERE_SERVER_URL`.
2. شغّل سير العمل **«بناء تطبيق Here للأندرويد»** من تبويب Actions (أو ادفع وسمًا `here-v0.1.0`).
3. نزّل `Here.apk` من المخرجات أو من صفحة الإصدارات.

> الغلاف يعرض تطبيق الويب من خادمك داخل التطبيق، لذا كل تحديث على الخادم يظهر فورًا بلا إعادة بناء.
> سير العمل يتبع نفس أسلوب تطبيق LiwaMusic في هذا المستودع لكنه لم يُشغَّل بعد؛ أول تشغيل قد يحتاج ضبطًا بسيطًا.

## تعديل المنتجات والفروع

كل شيء في `data/menu.json`:
- `products`: الاسم بالعربي/الإنجليزي، السعر، التصنيف، الوصف، الصورة (`public/img/products/`)، مجموعة الخيارات، وسوم `popular`/`new`.
- `optionGroups`: الحليب والسكر والثلج والإضافات والأحجام وأسعارها.
- `branches`: الفرعان (حديقة الشيخة سلامة بنت بطي، مزيرعة) بساعات العمل وروابط الخرائط وطرق الاستلام المتاحة.
- `ordering`: رسوم التوصيل والحد الأدنى والوقت المتوقع.
- `loyalty`: قواعد النقاط والمستويات.

الإيقاف المؤقت لصنف أو تغيير سعره يتم من شاشة الكوفي بلا لمس الملف.

## ما الذي يلزم قبل الإطلاق الفعلي؟

- **تحقق برقم الهاتف (OTP)**: التسجيل الحالي بالهاتف فقط بلا تحقق — مناسب للتجربة، ويلزم قبل الإطلاق ربط SMS/WhatsApp OTP (مثل Twilio Verify) في `POST /api/auth/login`.
- **الدفع الإلكتروني**: الدفع الآن نقدًا أو بالبطاقة عند الاستلام. لإضافة الدفع داخل التطبيق يُربط مزوّد إماراتي (Tap, PayTabs, Stripe UAE) في خطوة تأكيد الطلب.
- **إشعارات الهاتف (Push)**: التطبيق يحدّث الحالة لحظيًا وهو مفتوح؛ للإشعار وهو مغلق يلزم Web Push (VAPID) أو FCM في غلاف الأندرويد.
- **قاعدة بيانات**: `db.json` كافٍ لكوفي واحد بآلاف الطلبات؛ عند التوسع لعدة فروع/أجهزة يُستبدل بـ SQLite/Postgres (الطبقة معزولة في `server.js`).

## واجهة البرمجة (مختصر)

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/api/menu` | القائمة والفروع والإعدادات |
| POST | `/api/auth/login` | `{phone, name}` ← رمز جلسة + بيانات العضو |
| GET | `/api/me` | العضو وطلباته وسجل نقاطه (Bearer) |
| GET | `/api/me/stream?token=` | بث حي لحالة الطلبات والنقاط (SSE) |
| POST | `/api/orders` | إنشاء طلب `{branchId, mode, items, car|address, note, redeemPoints, payment}` |
| GET | `/api/orders/:id` | تفاصيل طلب |
| POST | `/api/admin/login` | التحقق من الرمز |
| GET | `/api/admin/orders` · `/stream` · `/stats` · `/customers` · `/products` | شاشة الكوفي (ترويسة `X-Admin-Pin`) |
| POST | `/api/admin/orders/:id/status` | `{status}` ← accepted / preparing / ready / completed / cancelled |
| PATCH | `/api/admin/products/:id` | `{available, price}` |
| POST | `/api/admin/points` | `{memberCode|phone, amountAed}` نقاط شراء مباشر |

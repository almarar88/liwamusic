# LiwaTube — يوتيوبك الخاص، محلي ومدعوم بالذكاء الاصطناعي

<div align="center"><strong>تم إنشاؤه عن طريق LiwaMusic</strong></div>

تطبيق **سطح مكتب لويندوز** يحوّل مجلدات الفيديو على جهازك إلى **يوتيوب خاص بك**:
واجهة يوتيوب المعروفة (الرئيسية، Shorts، الاشتراكات، السجل، شاهد لاحقًا، قوائم التشغيل،
صفحة مشاهدة مع «التالي» وتشغيل تلقائي) — لكن كل شيء **على جهازك فقط**، بلا حساب ولا رفع.
ومع مفتاح Anthropic API اختياري، يصبح لديك **ذكاء اصطناعي يشاهد فيديوهاتك** ويكتب لها عناوين
ووصفًا وفصولًا، ويبحث فيها بلغة طبيعية، ويوصيك بما تشاهده، ويجيبك عن أسئلتك أثناء المشاهدة.

## نسختان في مجلد واحد

| | **LiwaTube Desktop** (`electron/`) | **LiwaTube Server + App** (`server/` + `web/` + `app/`) |
|---|---|---|
| لمن؟ | لك وحدك على جهاز ويندوز | أنت ترفع، **والجميع يشاهد** |
| المصدر | مجلدات الفيديو على قرصك | مقاطع ترفعها من **لوحة التحكم** |
| المشاهدون | أنت | أي شخص يفتح الرابط أو يثبّت **APK** على الهاتف أو تلفاز أندرويد |
| البيانات | على جهازك | على خادمك (VPS، أو جهازك مع نفق، أو Docker) |

الواجهة والمشغّل والتوصيات والذكاء الاصطناعي **مشتركة** بين النسختين.

## ⚡ الطريقة الأسهل: «مشاركة» من تطبيق الويندوز (بلا حسابات، بلا رفع)

1. ثبّت **LiwaTube لويندوز** وأضف مجلد فيديوهاتك.
2. افتح صفحة **«مشاركة»** من الشريط الجانبي واضغط **تشغيل المشاركة**.
   يصبح كمبيوترك خادم LiwaTube فورًا، ويظهر **رابط ورمز QR**.
3. **داخل البيت**: أي هاتف أو تلفاز على نفس الواي‑فاي يمسح الرمز (أو يكتب الرابط في تطبيق LiwaTube) ويشاهد كل مكتبتك.
4. **من أي مكان**: اضغط **«مشاركة على الإنترنت»** فيُنزَّل نفق Cloudflare تلقائيًا (بلا حساب) ويعطيك رابط `https://….trycloudflare.com` أرسله لمن تريد.
   الرابط يتغيّر عند كل تشغيل، وكمبيوترك يجب أن يبقى مفتوحًا أثناء المشاهدة.

لوحة التحكم (Studio) متاحة من الهاتف أو المتصفح بكلمة المرور المعروضة في الصفحة، وتستطيع رفع مقاطع إضافية من هناك أيضًا.

> تريد رابطًا ثابتًا لا يعتمد على تشغيل كمبيوترك؟ انظر «الخادم المستقل» أدناه (Railway).

## 📡 الخادم المستقل: ارفع مرة واحدة، يشاهد الجميع (رابط ثابت، دائم)

### تشغيل الخادم

```bash
cd liwatube
npm install
LIWATUBE_ADMIN_PASSWORD=كلمة-سر-قوية npm run server
# → http://localhost:8787   (البيانات في liwatube/server-data)
```

أو بـ Docker:

```bash
cd liwatube/server
docker compose up -d      # عدّل LIWATUBE_ADMIN_PASSWORD في docker-compose.yml أولًا
```

متغيرات البيئة: `PORT` (افتراضي 8787)، `LIWATUBE_DATA` (مجلد المقاطع وقاعدة البيانات)،
`LIWATUBE_ADMIN_PASSWORD` (إن لم تُمرَّر، أول من يضغط «دخول المشرف» يعيّنها)، `ANTHROPIC_API_KEY` (اختياري).

### لوحة التحكم (Studio)

افتح الرابط ← **دخول المشرف** ← ستجد:

- **رفع**: اسحب المقاطع (MP4/WebM/MKV/MOV بأي حجم). تُرفع مباشرة، ويولّد متصفحك الصورة المصغّرة والمدة تلقائيًا.
- **المقاطع**: تعديل العنوان/الوصف/الوسوم/القناة، إخفاء/إظهار، رفع ترجمة SRT/VTT، تحليل بالذكاء، حذف.
- **الإعدادات**: اسم الموقع، رسالة ترحيب، السماح بالتعليقات، مفتاح Claude والنموذج، وهل يستخدم الزوار الذكاء أم أنت فقط.

كل ما ترفعه يظهر **فورًا** لكل من يفتح الموقع أو التطبيق. الزوار لا يحتاجون حسابًا:
المشاهدات والإعجابات والتعليقات تُحسب لكل جهاز، وسجلهم و«شاهد لاحقًا» وقوائمهم تبقى على أجهزتهم.

### أسهل طريقة ليعمل عند الآخرين (مُوصى بها): Railway

اخترتها لأنها الوحيدة التي تجمع: نشر من GitHub بلا أوامر، **تخزين دائم للمقاطع**، رابط https ثابت،
وتكلفة ~5$ شهريًا تشمل التخزين الأول. الخطوات كلها في المتصفح:

1. افتح [railway.com](https://railway.com) وسجّل بحساب GitHub ← **New Project ← Deploy from GitHub repo** ← اختر `almarar88/liwamusic`.
   سيكتشف `Dockerfile` في الجذر ويبني الخادم تلقائيًا.
2. في الخدمة: **Settings ← Volumes ← Add Volume** ومسار التركيب `/data` (هنا تُحفظ المقاطع، ولا تضيع عند التحديث).
3. **Settings ← Networking ← Generate Domain** ← يظهر رابط مثل `https://liwatube-production.up.railway.app`.
4. (اختياري) **Variables**: `LIWATUBE_ADMIN_PASSWORD` = كلمة مرورك. وإلا تعيّنها من الموقع عند أول «دخول المشرف».

افتح الرابط ← دخول المشرف ← ارفع. انتهى. **ثم** ابنِ الـ APK بهذا الرابط (انظر أدناه) فيفتح عند الآخرين مباشرة بلا أي إعداد.

بدائل بنفس الملفات: **Render** (زر Blueprint من `render.yaml`، القرص الدائم يتطلب خطة Starter)،
أو أي VPS/NAS بـ Docker: `docker run -d -p 8787:8787 -v liwatube:/data ghcr.io/almarar88/liwatube:latest`
(الصورة تُنشر بوسم `tube-server-v*`).

### كيف يصل الآخرون إليه؟

| الحالة | ما تفعله |
|---|---|
| داخل البيت/الشبكة نفسها | أعطهم `http://<IP-جهازك>:8787` |
| من الإنترنت — الأسهل | خادم VPS صغير (أي مزود) + `docker compose up -d` |
| من الإنترنت — من جهازك | نفق مثل Cloudflare Tunnel أو Tailscale Funnel يعطيك رابط https ثابتًا |

> للاستخدام على الإنترنت ضع الخادم خلف https (نفق أو Caddy/Nginx) لأن كلمة مرور المشرف تُرسل عبر الاتصال.

## 📱📺 التطبيق: هاتف + تلفاز في APK واحد

### **[⬇ تحميل LiwaTube.apk (هاتف + تلفاز أندرويد)](https://github.com/almarar88/liwamusic/releases/download/tube-android-v1.2.0/LiwaTube.apk)**

`LiwaTube.apk` · ~3 ميجابايت · أندرويد 6+ · [كل الإصدارات](https://github.com/almarar88/liwamusic/releases)

`liwatube/app/` هو تطبيق Capacitor يغلّف نفس الواجهة. عند أول تشغيل يطلب **الرابط الظاهر في صفحة «مشاركة»** على الكمبيوتر
(أو رابط خادمك المستقل)، ثم يعمل مثل يوتيوب. مسح رمز QR بكاميرا الهاتف يفتح الرابط في المتصفح مع زر «فتح في تطبيق LiwaTube»:

- **الهاتف**: شريط تنقّل سفلي، بطاقات بعرض الشاشة، مشغّل يملأ العرض، Shorts بالتمرير.
- **تلفاز أندرويد** (Android TV / Google TV / أي شاشة تقبل APK): يظهر في مشغّل Leanback، والتنقّل بأسهم الريموت،
  OK للتشغيل، Back للرجوع، مفاتيح التشغيل/الإيقاف والتقديم. خطوط أكبر وإطار تركيز واضح.
- **وضع التلفاز** يُكتشف تلقائيًا ويمكن فرضه من الإعدادات.

- **الهواتف القابلة للطي (Fold/Flip)** وتقسيم الشاشة: التخطيط يعيد ترتيب نفسه عند الطي/الفرد بلا إعادة تحميل.

بناء الـ APK: شغّل سير العمل «بناء LiwaTube للأندرويد» من تبويب Actions (أو ادفع وسمًا `tube-android-v1.0.0`).
**ضع رابط خادمك في حقل `server_url`** فيُضمَّن في التطبيق ويفتح عند الآخرين مباشرة بلا أي إدخال.
(يمكن بدلًا من ذلك ضبط متغير المستودع `LIWATUBE_SERVER` مرة واحدة من Settings ← Variables.)
يُنشر `LiwaTube.apk` في Releases؛ أرسل رابطه لمن تريد. محليًا:

```bash
cd liwatube/app && npm install && npm run build:www && npx cap add android && npx cap sync android
node scripts/patch-android.mjs android && python3 scripts/make-icons.py android/app/src/main/res
cd android && ./gradlew assembleRelease
```

الواجهة نفسها تعمل أيضًا كموقع/PWA من أي متصفح بلا تثبيت.

## 🚀 البدء في 30 ثانية (نسخة سطح المكتب)

1. افتح التطبيق واضغط **إضافة مجلد** — أو اسحب مجلد الفيديوهات وأفلته داخل النافذة.
2. تبدأ الفهرسة فورًا: كل مجلد فرعي يصبح **قناة**، وتُولَّد الصور المصغّرة والمدد تلقائيًا (بلا ffmpeg).
3. اضغط أي بطاقة للمشاهدة. البقية اختيارية.

## ما الذي يشبه يوتيوب؟

| الميزة | التفاصيل |
|---|---|
| **الرئيسية** | شبكة بطاقات مع رقائق تصفية، «تابع المشاهدة»، توصيات من محرك محلي يتعلم من سلوكك |
| **Shorts** | كل فيديو أقصر من الحد (60 ث افتراضيًا) أو عمودي يظهر في تغذية عمودية بالتمرير |
| **القنوات والاشتراكات** | القناة = المجلد. اشترك لتظهر فيديوهاتها الجديدة في «الاشتراكات» والشريط الجانبي |
| **صفحة المشاهدة** | مشغّل مخصّص: شريط تقدّم بالفصول، معاينة الوقت، سرعة، PiP، وضع المسرح، ملء الشاشة، ترجمات SRT/VTT المجاورة |
| **التالي والتشغيل التلقائي** | قائمة جانبية بفيديوهات مشابهة (نفس القناة، الوسوم، العنوان) مع مفتاح تشغيل تلقائي |
| **المشغّل المصغّر** | غادر صفحة المشاهدة والفيديو يستمر في زاوية النافذة |
| **إعجاب / شاهد لاحقًا / قوائم** | مثل يوتيوب تمامًا، مع قوائم تُنشأ يدويًا أو بالذكاء الاصطناعي |
| **السجل** | مجمّع حسب اليوم، مع استئناف من آخر موضع |
| **معاينة عند التمرير** | تشغيل صامت عند الوقوف على البطاقة |
| **ملاحظات خاصة** | «تعليقات» لا يراها أحد غيرك |
| **اختصارات** | `K` `J` `L` `F` `T` `I` `M` `C` `0–9` `Shift+N` `<` `>` `,` `.` `/` |

## 🤖 الذكاء الاصطناعي (اختياري، مغلق افتراضيًا)

يعمل عبر Claude بمفتاح تضعه أنت (الإعدادات ← الذكاء الاصطناعي). المفتاح يُخزَّن مشفّرًا
بـ Windows DPAPI ولا يغادر العملية الرئيسية.

- **فهم الفيديو**: يلتقط التطبيق إطارات موزّعة على المدة ويرسلها مع اسم الملف (والترجمة إن وُجدت)،
  فيعود بعنوان ووصف ووسوم وتصنيف و**فصول بطوابع زمنية** و**أفضل إطار كصورة مصغّرة**.
- **بحث ذكي**: «فيديوهات الطبخ اللي فيها بحر» — يفهم القصد ويشرح كيف فهمه.
- **لك**: توصيات شخصية من مكتبتك مع سبب لكل اقتراح.
- **اسأل عن الفيديو**: محادثة أثناء المشاهدة، الطوابع الزمنية في الإجابة قابلة للنقر.
- **قوائم ذكية**: «مقاطع قصيرة تحفيزية لصباح الأحد».
- **تقرير رؤى** عن ذوقك وما لم تشاهده بعد.

## 🔒 الخصوصية

- لا خادم، لا حساب، لا اتصال بالإنترنت إلا عند استدعاء الذكاء الاصطناعي بطلبك.
- **قفل PIN** اختياري عند التشغيل وعند الخمول (يُخزَّن مشتق scrypt فقط).
- البيانات في `%APPDATA%\LiwaTube\data` كملفات JSON قابلة للنسخ الاحتياطي.

## الصيغ

يشغّل ما يشغّله Chromium مباشرة: **MP4 / M4V / MOV (H.264/AAC)، WebM، MKV (H.264/VP9 + AAC/Opus)، OGV**.
ملفات AVI/WMV/FLV/TS تُفهرس وتُعلَّم بأنها قد لا تعمل — حوّلها إلى MP4.

## التطوير

```bash
cd liwatube
npm install
npm test          # اختبار ذاتي (الوحدات + واجهة الخادم HTTP)
npm start         # تشغيل نسخة سطح المكتب (Electron)
npm run server    # تشغيل الخادم على 8787
npm run dist:win  # مثبّت ويندوز
```

البنية: `electron/` (سطح المكتب) · `server/` (الخادم) · `web/` (جسر HTTP + لوحة التحكم + هاتف/تلفاز) · `app/` (APK) · `renderer/` (الواجهة المشتركة).

البناء الرسمي عبر GitHub Actions: `.github/workflows/build-liwatube.yml` (وسم `tube-v*`).
